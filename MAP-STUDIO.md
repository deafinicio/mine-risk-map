# EORE Atlas — мапа сесій

Мапа та дашборд використовують спільну візуальну мову EORE Analytics: Manrope / Orbitron, прозорі панелі, блакитні, м’ятні та фіолетові акценти.

## Структура

- `index.html`: завантаження реєстру сесій, геоприв’язка, фільтри, Leaflet, експорт PNG.
- `map-studio.css`: адаптивний інтерфейс, SVG-маркери, панелі, анімації та режими доступності.
- `map-studio.js`: нові кластери й картки, перемикачі шарів і режимів, рух, повноекранний режим, обробка порожніх вибірок.
- `map-heat.js`: WebGL2 / GLSL та резервний Canvas-рендерер.
- `air-mode.js`: наявна логіка повітряних загроз, узгоджена з новим інтерфейсом.

Збірка і додатковий сервер не потрібні. Дані та джерела сесій збережено. Оригінальні звітні документи не додаються.

## Теплова карта

Два GPU-проходи: накопичення ваг у текстурі та кольорове поле з делікатними контурами. Збіги координат агрегуються перед передаванням на GPU. Ваги залежать від числа учасників, нормалізації поточної вибірки, масштабу й параметрів налаштувань. Кластери відображають кількість сесій; наведення показує сесії та учасників.

Це відносна візуалізація проведеного інформування, а не шкала мінної небезпеки чи точний растр абсолютних кількостей. Кольори та площі плям між різними вибірками не слід трактувати як абсолютне порівняння.

Якщо WebGL2 не підтримується, не вдалося зібрати шейдери або втрачено контекст, автоматично вмикається локальна `Leaflet.heat 0.2.0`. Шар зберігає ті самі дані та керування. Динамічне забарвлення не пересуває точки й не змінює числа.

## Рух і ресурси

- Native Web Animations, CSS та SVG. Географічні координати маркерів не анімуються декоративними ефектами.
- Кнопка з хвилею вимикає ефекти; вибір зберігається локально. Ураховано `prefers-reduced-motion`.
- GPU-поле оновлює накопичення лише після зміни даних, масштабу чи розміру; декоративний прохід обмежений приблизно 22 кадрами/с.
- Буфер обмежено 1,5 млн пікселів. Прихована вкладка зупиняє цикл; видалення шару звільняє GPU-ресурси.
- WebGL-буфер зберігається для експорту PNG. Панелі мають непрозорий резервний фон без `backdrop-filter`.

## Перевірка

```sh
node tests/map-studio.test.cjs
python tests/map-shaders.py
```

Перший тест використовує лише Node.js. Другий додатково потребує Mesa/EGL з підтримкою OpenGL ES 3 і компілює ті самі GLSL-шейдери; перевіряє накопичення та колір за фактичними пікселями без браузера.

У браузері перевірено: фільтри, порожню вибірку, картку сесії, PNG, перемикання сесій / AIR, демо-шар AIR, резервний рендерер, мобільний інтерфейс 390 px і вимкнення ефектів. У тестовому браузері WebGL2 недоступний; шейдери виконано окремо через Mesa/OpenGL ES.
