## 📌 Overview

The project provides a full pipeline:

- data collection via web form  
- storage in Google Sheets  
- API via Google Apps Script  
- visualization using Leaflet  

Including:

- interactive map  
- clustering  
- heatmap (based on beneficiaries)  
- filtering and export
